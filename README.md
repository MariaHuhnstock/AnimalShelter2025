
# AnimalShelter

A C# animal shelter management application developed as a learning project during my 20-week internship at Buss-IT-Labs.

## About the Project

AnimalShelter is a console application for managing animals in a fictional animal shelter.

The project focuses on object-oriented programming concepts, particularly inheritance and polymorphism.

## Features

- Add animals to the shelter
- Manage dogs, cats, and birds
- Display available animals
- Adopt animals by name
- Save and load shelter data
- Navigate through a console-based menu

## Technologies

- C#
- .NET 10
- Console Application
- Object-Oriented Programming
- Inheritance and Polymorphism
- File I/O

## Getting Started

### Requirements

- .NET 10 SDK
- Visual Studio or another compatible IDE

### Run the Application

Open the project in Visual Studio or navigate to the directory containing the `.csproj` file and run:

```bash
dotnet run
```
